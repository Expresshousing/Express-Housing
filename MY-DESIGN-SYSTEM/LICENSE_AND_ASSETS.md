# Licensing and Asset Boundaries

## Package content

The documentation, token definitions, CSS foundations, and generic examples in this package were created as an extraction of the user’s own implemented visual direction. They are intended for the user’s reuse. This file does not grant rights to third-party fonts, icons, photographs, trademarks, or libraries.

## Photography

No source photography is copied into this package.

The current app’s images include operator-supplied files and official building/model imagery with project-specific authorization. That authorization should **not** be assumed to cover unrelated projects. For a new app:

1. use newly licensed or owned photography;
2. keep a source, creator, license, date, and permitted-use record for every asset;
3. avoid suggesting a model/shared space is an exact item, unit, person, or outcome;
4. remove embedded metadata if privacy or location data is unnecessary;
5. provide meaningful alt text or empty alt text for decorative images.

## Font

Inter is available under the SIL Open Font License 1.1. If self-hosting, keep the upstream license with distributed font files. If using Google Fonts, review the destination product’s privacy policy and content-security policy.

## Icons

The source uses Lucide. If Lucide icons are copied or installed, retain its applicable license notice. Do not mix unrelated filled, outlined, and branded icon families without a deliberate visual rule.

## Product and brand names

“Express Housing,” building names, addresses, customer/guest names, and source copy are intentionally not part of this reusable visual package. Substitute the destination product’s own identity and content.

## Recommended asset register fields

`filename`, `source URL`, `creator/owner`, `license`, `permission evidence`, `download date`, `allowed products`, `expiration`, `required attribution`, `model/property release`, `editorial limitations`, `alt text`, and `focal point`.
