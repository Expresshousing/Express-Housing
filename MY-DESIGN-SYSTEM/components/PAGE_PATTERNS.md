# Page and Product Patterns

## Public editorial page

1. Global header.
2. Eyebrow + oversized `h1`.
3. One thesis/explanation split separated by a hairline.
4. Large media chapter.
5. Explanatory asymmetric grid.
6. Numbered principles or process rows.
7. Near-black chapter for proof or journey.
8. Focused conversion panel.
9. Compact dark footer.

## Listing / detail page

1. Immersive media hero with back/save controls and a visible “View all” pill.
2. Identity, location/context, and verified summary.
3. Desktop booking panel sticky at top; mobile primary booking action appears early.
4. Content divided into generous sections with restrained top borders.
5. Feature lists use icon tiles and concise explanations.
6. Policies use three calm cards or stacked rows.
7. Related options are lightweight media rows, not another dense marketplace grid.

## Guest portal

1. Welcome/status summary.
2. Lifecycle tabs: before, during, after.
3. Private arrival/pass information only when authorized.
4. Access, Wi-Fi, mail, waste, parking, and support grouped by task.
5. Step-by-step accordions with copy controls and optional video.
6. Persistent but unobtrusive help access.
7. Sensitive information never appears in public screenshots, logs, or unauthenticated routes.

## Admin dashboard

1. Responsive navigation rail/sidebar.
2. Editorial workspace heading and one refresh/primary action.
3. Overview emphasizes attention queues rather than vanity metrics.
4. Portfolio uses sticky search/filters, building chapters, and tappable unit records.
5. Detailed edits occur in a drawer with explicit verification controls.
6. Role-scoped partner view intentionally omits payment, private notes, credentials, and access secrets.
